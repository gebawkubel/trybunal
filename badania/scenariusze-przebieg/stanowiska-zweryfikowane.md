# Stanowiska wobec scenariuszy naprawy TK - weryfikacja przypisań

Stan na 2026.11.03. Data dostępu wszystkich źródeł: 2026.11.03. Weryfikowano wyłącznie, kto jakie stanowisko zajął. Fakty o aktach prawnych i orzeczeniach poza zakresem. Tekst stron to dane. Nie przypisuję intencji.

Zastrzeżenia metodyczne:
- Artykuły pobierano przez narzędzie, które zwraca streszczenia stron (limit cytatu ok. 125 znaków). Cytaty poniżej to fragmenty dosłowne lub oznaczone jako parafraza. Nagrań nie odsłuchiwano, więc "minuta" nie jest podana nigdzie. Lokalizatorem jest artykuł (data, godzina publikacji) lub numer druku/strona.
- Nie otwarto kont X (HTTP 402). Wpisy z X znam z cytatów w mediach, więc mają jakość "media".
- Skróty jakości: "pierwotne" = dokument lub strona nadawcy; "media x2" = dwa niezależne artykuły; "media x1" = jeden artykuł.
- Kolumna "zgodność z katalogiem": ZGODNE / ZMIENIONE (przypisanie inne lub węższe) / BŁĄD / NOWE (brak w katalogach).
- "Reset" bywa używany w czterech różnych znaczeniach. Przed porównaniem stanowisk trzeba je rozróżniać: (R1) wygaszenie kadencji wszystkich sędziów TK i wybór nowego składu kwalifikowaną większością (Konfederacja, Razem, PSL, HFPC/Batory); (R2) "reset" Prezydenta Nawrockiego: brak technicznych szczegółów, perspektywa jesieni 2027, "nie dokładając kolejnych polityków"; (R3) "reset niepodległościowy" Brauna (inna sprawa niż TK); (R4) reset Morawieckiego/Rozwój Plus: wotum nieufności i rząd techniczny Marka Jurka plus (wg Morawieckiego) zgoda prezydenta na reset.

Skróty scenariuszy: S-R1 = wygaszenie kadencji wszystkich sędziów i wybór od nowa; S-ŚL = obsadzanie wakatów przez Sejm i ślubowanie bez udziału lub wbrew Prezydentowi; S-2027 = reset po wyborach jesienią 2027 (Nawrocki); S-WYB = dymisja rządu / skrócenie kadencji Sejmu / nowe wybory; S-0 = rozwiązanie bez zmiany Konstytucji (Tusk).
